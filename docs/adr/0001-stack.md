# ADR 0001: стек

Дата: 2026-10-02. Статус: принято.

- Сервер на **Go**: язык владельца проекта, один бинарник, мало памяти на VPS.
- Клиент на **Expo (React Native, TypeScript)**: один код на Android и iOS, iOS собирается в облаке без Mac.
- **PostgreSQL**: связи «пользователь, список, позиции», поиск `pg_trgm`.
- Вход **только по email-коду**: так App Store не требует Sign in with Apple (правило 4.8). Google/Apple добавим вместе, если понадобится.
- Хостинг на своём VPS (Docker Compose + Caddy).
